# Getting Started with MangoAI.gg

MangoAI.gg provides rapid generation of Roblox Luau code directly inside your web application without third-party key management.

## Using Special Characters & Formatting

You can use special characters in your prompts or ask the AI to format its answers using Markdown standard prefixes:

  • # Text — Renders a prominent Heading 1 (Yellow)
  • ## Text — Renders a Heading 2 sub-header (Mango Orange)
  • ### Text — Renders a Heading 3 section header (Leaf Green)
  • ```luau ... ``` — Renders an interactive code snippet with a copy button.
Example Prompt: "## Explain how task.spawn works in Luau with an example"
